# Кудайберген - Техническое Задание и Бизнес Логика

## 1. Описание Проекта

**Кудайберген** — мобильное приложение-маркетплейс для покупки и продажи автозапчастей в Казахстане. Платформа соединяет покупателей (владельцев автомобилей) с продавцами (авто-магазинами, сервисами, частными продавцами) через систему запросов и предложений.

**Регион:** Казахстан (Астана, Алматы и другие города)  
**Язык:** Русский и казахский  
**Платформа:** React Native (iOS, Android, Web)  
**Целевая аудитория:** Владельцы автомобилей, авто-магазины, сервисные центры

---

## 2. Ключевые Роли

### 2.1 Покупатель
- Владелец автомобиля
- Ищет нужные запчасти
- Создаёт запрос на поиск детали
- Получает предложения от продавцов
- Взаимодействует с продавцом через чат
- Оставляет отзыв и рейтинг

### 2.2 Продавец
- Авто-магазин, сервис или частный продавец
- Просматривает запросы покупателей
- Отправляет коммерческие предложения
- Общается с покупателем
- Управляет своим каталогом товаров
- Отслеживает статистику (конверсия, рейтинг)

---

## 3. Основные Бизнес-Процессы

### 3.1 Процесс Поиска и Покупки (Покупатель)

```
1. Покупатель входит в приложение
2. Указывает свой автомобиль (модель, год, объём двигателя)
3. Создаёт запрос на нужную деталь:
   - Описывает что нужно
   - Выбирает категории (Амортизаторы, Колодки и т.д.)
   - Может добавить фото
   - Отмечает срочность
4. Система публикует запрос всем продавцам в регионе
5. Продавцы получают уведомление и отправляют предложения
6. Покупатель видит список предложений с ценами и рейтингами продавца
7. Покупатель выбирает лучшее предложение
8. Начинается общение через чат
9. Согласование деталей (цена, доставка, оплата, доставка)
10. Встреча/доставка
11. Оплата
12. Оставление отзыва о продавце
```

**Временные лимиты:**
- Запрос активен 24-72 часа
- Продавец должен ответить в течение 30 минут (рейтинг)
- История запросов хранится 6 месяцев

### 3.2 Процесс Продажи (Продавец)

```
1. Продавец входит в приложение
2. Просматривает новые запросы в его категориях
3. Видит информацию:
   - Марка/модель автомобиля
   - Год выпуска
   - Объём двигателя
   - Описание нужной детали
   - Количество других предложений
4. Создаёт коммерческое предложение:
   - Указывает цену
   - Добавляет описание
   - Указывает время доставки
   - Может добавить условия (гарантия, возврат)
5. Предложение публикуется
6. Покупатель выбирает это предложение
7. Начинается чат
8. Согласование деталей
9. Выполнение сделки
10. Получение оценки от покупателя
```

**Метрики продавца:**
- Рейтинг (средняя оценка покупателей)
- Конверсия (% предложений → сделок)
- Время ответа (средний)
- Количество выполненных заказов
- Статус верификации

### 3.3 Система Чатов

```
Начало чата:
1. Покупатель выбирает предложение продавца
2. Автоматически открывается чат
3. История сообщений загружается
4. Показывается информация о товаре прямо в чате

Функциональность чата:
- Текстовые сообщения
- Отправка фото
- Голосовые сообщения (опционально)
- Информация о товаре (цена, гарантия)
- Быстрые действия (забронировать, согласиться)
- Уведомления о новых сообщениях

Закрытие чата:
- После завершения сделки
- По инициативе пользователя
- Автоматически через 30 дней без активности
```

## 5. Система Рейтинга и Отзывов

### 5.1 Рейтинг Продавца
- Базируется на отзывах покупателей (1-5 звёзд)
- Вес недавних отзывов выше
- Минимум 5 сделок для отображения рейтинга
- Показывает:
  - Общая оценка (4.5 из 5)
  - Количество отзывов (24)
  - Распределение оценок

### 5.2 Критерии Оценки
- Соответствие описанию
- Качество товара
- Честность цены
- Скорость ответа
- Удобство встречи
- Профессионализм

### 5.3 Система Доверия
- Новый продавец (зелёный статус - нужна верификация)
- Проверенный продавец (синий - прошёл модерацию)
- Партнёр платформы (золотой - долгосрочный)
- Заблокированный (красный - нарушения)

## 7. Безопасность и Модерация

### 7.1 Верификация
- Проверка телефона (SMS)
- Проверка email
- Для продавцов: проверка ИНН/регистрации
- Фото документа

### 7.2 Правила Платформы
- Запрещены оскорбления в чатах
- Автоматическое удаление контактов в сообщениях (кроме согласованных)
- Запрещены ссылки на внешние сайты
- Запрещены повторяющиеся запросы

### 7.3 Система Жалоб
- Покупатель может пожаловаться на продавца
- Продавец может пожаловаться на покупателя
- Модератор рассматривает жалобу
- Решение: блокировка, предупреждение, штраф

---

## 8. Экономика Платформы

### 8.1 Доход Платформы
- Комиссия за сделку: 2-5% (зависит от типа продавца)
- Подписка для продавцов (премиум = больше видимости): 5000-10000 KZT/месяц
- Реклама товаров/магазинов
- Спонсорство ТОПа категорий

### 8.2 Система Премиум
**Для Продавца (Premium):**
- Выделение в списке запросов
- Больше видимости (+20% просмотров)
- Аналитика подробная
- Бейдж "Premium Seller"
- Поддержка 24/7

**Для Покупателя (Premium):**
- Быстрый ответ (приоритет)
- Скрытие контактов от конкурентов
- История всех запросов
- Расширенный поиск
